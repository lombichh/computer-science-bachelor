# Computer Science Bachelor's Degree

Backup repository for all coursework and materials related to my Bachelor's Degree in Computer Science at Università di Bologna.

## Repository Structure

The repository is organized by academic years, semesters and courses:

```text
.
├── first-year/
│   ├── first-semester/
│   │   └── <course-name>/
│   │       ├── exams/       # Past exam papers and solutions
│   │       ├── utils/       # Lecture notes, summaries, and utilities
│   │       └── ...
│   └── second-semester/
│       └── <course-name>/
├── second-year/
│   ├── first-semester/
│   └── second-semester/
├── third-year/
│   ├── first-semester/
│   └── second-semester/
